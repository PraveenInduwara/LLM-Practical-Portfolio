# Lab 6 — AI Agents

## Objective

Build tool-using AI agents with a local Ollama model, add memory and RAG tools, and explore workflow automation with n8n and Google services.

## Practical structure

- `notebooks/` — notebooks or code examples for the agent practical.
- `screenshots/` — screenshots of working agents and n8n workflows.

## Lab activities

- Build a calculator agent using Ollama and test its tool-calling loop.
- Expand the agent with date/time, Notepad, file search, file creation, and system-information tools.
- Add persistent conversation memory with SQLite and a memory-search tool.
- Add a RAG search tool using the university knowledge base from Lab 5.
- Explore Google Calendar tools for checking schedules and creating events.
- Run n8n locally with Docker and connect an Ollama chat model.
- Plan an intelligent university assistant workflow using RAG, calendar, Sheets, Docs, and Gmail integrations.

## Progress

Implementation, outputs, and screenshots will be added as the practical is completed.
