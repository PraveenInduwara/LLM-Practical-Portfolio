# Lab 01: Machine Learning

## Objective

Practice basic natural language processing (NLP) tasks.

## Practical Information

- **Topic:** Text Preprocessing, TF-IDF and Machine Learning
- **Duration:** 1 hour
- **Programming language:** Python
- **Libraries:** Pandas, NumPy, NLTK, Scikit-learn, Matplotlib, Seaborn
- **Dataset:** [Sentiment Labelled Sentences](https://archive.ics.uci.edu/dataset/331/sentiment%2Blabelled%2Bsentences)

## Tasks

1. Download and load the dataset.
2. Perform basic text preprocessing:
   - Convert text to lowercase.
   - Remove unnecessary characters and punctuation.
   - Remove extra whitespace.
   - Create a clean-text column.
   - Compare the original and preprocessed text.
3. Explore the text data:
   - Display positive and negative examples.
   - Identify frequently occurring words.
   - Observe differences between positive and negative reviews.
4. Split the dataset.
5. Create a bag-of-words (BOW) representation.
6. Train a machine learning model, such as SVM or Logistic Regression.
7. Evaluate the model’s performance using accuracy, precision, recall, and F1 score.
8. Test the model with a new sentence.
